hintsFilter GFF
Annotation Filter for BRAKER
 
Overview
HintsFilter GFF is a Python based tool that filters gene annotations from BRAKER (or any GFF/GTF file) using external evidence (hints) and quality criteria. It produces a confident gene set—perfect for downstream analyses such as functional annotation, comparative genomics, or publication ready datasets.
The tool comes with a graphical user interface (GUI) built with Tkinter, making it easy for biologists and bioinformaticians to run the pipeline without command line expertise.

What It Does
1.	Reads a GFF/GTF file (BRAKER output) and a corresponding hints file (e.g., from RNA seq or protein homology).
2.	Indexes hints by genomic position.
3.	Extracts gene features, transcripts, exon counts, protein lengths, and BRAKER scores (if available).
4.	Classifies genes based on:
•	Presence of hints within a defined margin.
•	Quality filters:
•	Minimum protein length (amino acids)
•	Minimum exon count
•	BRAKER score (only in ab initio mode)
5.	Generates:
•	A filtered GFF3 file with only confident genes.
•	Lists of gene IDs (confident / without hints).
•	Filtered EggNOG and InterProScan annotation files.
•	A detailed report.

How It Works (Step by Step)
1.	Load hints – The tool reads the hints GFF, indexes them by chromosome, and sorts them by position.
2.	Parse GFF – It extracts all gene and transcript features. For each transcript, it:
•	Counts exons.
•	Estimates protein length (sum of CDS lengths ÷ 3).
•	Retrieves the BRAKER score (if present in the score column).
3.	Classify genes – For every gene:
•	It looks for hints within a user defined margin around the gene boundaries.
•	A gene is considered “with hints” if at least one hint with score ≥ min_score overlaps the expanded region.
•	It also checks quality criteria: protein length ≥ min_len, exon count ≥ min_exons, and (only in ab initio mode) BRAKER score ≥ min_score.
4.	Build confident set – By default (non ab initio), a gene is kept if it has hints OR passes the quality filters. In ab initio mode, only quality filters are used.
5.	Filter files – The confident gene list is used to:
•	Write a new GFF3 containing only the features (genes, mRNAs, CDS, exons, etc.) belonging to confident genes.
•	Filter EggNOG and InterProScan TSV files by matching protein IDs to confident genes using multiple strategies (direct, suffix removal, transcript mapping, regex).
6.	Produce report – A plain text summary of all parameters and counts.

Input Files
You need four input files (except when using ab initio mode, where hints are optional):
File	Description	Format
GFF/GTF	Gene annotation file from BRAKER (or any compatible tool).	GFF3 or GTF (tab separated)
Hints	Evidence file (e.g., hints.gff) generated by BRAKER from RNA seq or protein alignments.	GFF
EggNOG	Functional annotation file from EggNOG mapper (*.emapper.annotations).	Tab separated, with header lines starting with #
InterProScan	Protein domain annotation file from InterProScan (TSV format).	TSV (tab separated)
Note: In ab initio mode, the hints file is not required, and the BRAKER score filter becomes active.

Output Files
All output files are written to a user specified directory. The following files are generated:
File	Description
braker_confident_only.gff3	Filtered GFF3 containing only confident genes and their sub features.
genes_confident.txt	List of gene IDs that passed the filters.
genes_without_hints.txt	List of gene IDs that had no hints (for reference).
eggnog_confident_only.emapper.annotations	EggNOG annotations filtered to confident genes.
interpro_confident_only.tsv	InterProScan annotations filtered to confident genes.
pipeline_report.txt	Comprehensive report with all parameters, counts, and file paths.

Installation
Prerequisites
•	Python 3.6+ (tested on 3.8, 3.9, 3.10)
•	Tkinter – usually included with Python on Linux/macOS/Windows; if not, install via your package manager (e.g., sudo apt install python3-tk on Debian/Ubuntu).
•	Required Python libraries:
•	pandas
•	numpy
Install Dependencies
bash
pip install pandas numpy
If you prefer a virtual environment:
bash
python3 -m venv venv
source venv/bin/activate   # Linux/macOS
# or venv\Scripts\activate on Windows
pip install pandas numpy
Download the Script
Save the script as hintsFilter_gui.py (or clone from the GitHub repository).

How to Run
1. Graphical Interface (Recommended)
Launch the GUI by running:
bash
python3 hintsFilter_gui.py
The window will appear. Use the Browse buttons to select your files, adjust the parameters, and click RUN PIPELINE. The execution log will show progress and any errors.
2. Command Line Mode (Advanced)
The script also supports command line arguments for use in pipelines or headless environments. Run:
bash
python3 hintsFilter_gui.py \
    -g /path/to/braker.gff3 \
    -x /path/to/hints.gff \
    -e /path/to/eggnog.emapper.annotations \
    -i /path/to/interpro.tsv \
    -o output_dir \
    --min-score 0.3 \
    --margin 500 \
    --min-protein-len 150 \
    --min-exons 2 \
    --min-braker-score 0.5 \
    --abinitio
Note: The --abinitio flag enables ab initio mode and activates the BRAKER score filter. Without it, the BRAKER score is ignored.

Parameters Explained
Parameter	GUI Label	Description	Default
--min-score	Min. hints score	Minimum score of a hint to be considered (0–1).	0.3
--margin	Margin (bp)	Flanking region around each gene to search for hints.	500
--min-protein-len	Min. protein (aa)	Minimum protein length to pass quality.	150
--min-exons	Min. exons	Minimum number of exons to pass quality.	2
--min-braker-score	BRAKER score ≥	Minimum BRAKER score (only used in ab initio mode).	0.3
--abinitio	Ab initio mode (checkbox)	Ignore hints; use only quality filters (including BRAKER score).	False

Understanding the Logic
With Hints (default)
•	A gene is confident if:
•	It has at least one hint (score ≥ min_score) within margin bp OR
•	It satisfies all quality criteria:
•	protein length ≥ min_protein_len
•	exon count ≥ min_exons
•	(BRAKER score filter is not applied)
Ab Initio Mode
•	Hints are completely ignored.
•	A gene is confident if:
•	protein length ≥ min_protein_len
•	exon count ≥ min_exons
•	BRAKER score ≥ min_braker_score
This is useful when you have no external evidence and want to rely on BRAKER’s intrinsic confidence scores.

Tips for Best Results
1.	Check your GFF – Ensure it contains exon and CDS features. If your BRAKER run used --prot_seq or --rnaseq, the score column may be empty; that’s why we ignore it by default.
2.	Adjust quality thresholds – Look at the statistics printed in the log (min, max, mean of protein length, exon count) to set realistic cutoffs.
3.	Margin – For protein based hints, a margin of 300 500 bp is safe. For RNA seq, 100 200 bp is usually enough.
4.	Test with lenient parameters first, then tighten filters to see how many genes are retained.

Troubleshooting
Issue	Likely Cause	Solution
No genes kept with strict filters	Protein length or exon cutoffs too high; or BRAKER score filter active accidentally.	Check the statistics in the log, lower the thresholds, or ensure --min-braker-score is 0 (or not used).
BRAKER score always 0	Your GFF has . in the score column (common with --prot_seq).	Disable the BRAKER score filter (default behaviour).
GUI not opening	Tkinter not installed.	Install Tkinter (sudo apt install python3-tk on Ubuntu).
EggNOG/InterPro files not filtered correctly	ID matching fails.	The script uses several strategies; check if your protein IDs match gene IDs patterns (e.g., g1, gene123, maker scaffold). If needed, adjust the regex in match_gene_id().
